安全提醒：电压上限默认 3.0 V（约 0.79 A），仍低于额定 1.4 A；软件上限为 5.0 V。 第一次测试请务必：电机固定好、手放在电源开关上、用电流表监控。

参数设置

固件三层限流始终生效，不能从页面解除：峰值 >1.6 A 开始折叠 allowed 电压、>2.6 A 循环级跳闸失能、 >4.5 A 中断级立即关断。状态栏的 pk / allowed / trips 就是它的实时读数。

指令作用说明
E使能并保持当前位置先锁定当前位置，再通电；随后发送 T<角度> 移动
