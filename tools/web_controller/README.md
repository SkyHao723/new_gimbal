# BLDC 云台电机 Web 控制器

一个**单文件**浏览器控制器，通过 **Web Serial API** 直接连接 USB-TTL，控制
**官方 SimpleFOC 2.4.0** 固件（工程：`New_gimbal/foc_official`）。

**不需要安装任何软件、不需要后端、不需要联网** —— 双击 `index.html` 即可。

---

## 1. 配套固件

| 项目 | 值 |
|---|---|
| 固件工程 | `New_gimbal/foc_official` |
| 库 | 官方 `askuric/Simple FOC` 2.4.0 |
| MCU | STM32F103C8T6（蓝板） |
| 驱动 | SimpleFOC Mini（DRV8316C） |
| 编码器 | AS5600（I2C） |
| 串口 | USART2，**PA2(TX) / PA3(RX)**，115200 8N1 |

固件命令集（本页面只使用这些）：

| 指令 | 作用 |
|---|---|
| `E` | 使能电机 |
| `D` | 失能 / 急停 |
| `T<角度>` | 目标角度 (rad)，如 `T0.5` |
| `V<电压>` | 电压上限 (V)，如 `V1.5` |
| `L<速度>` | 速度上限 (rad/s) |
| `R` | 读编码器（角度 / 速度 / 机械角） |
| `?` | 状态（EN / angle / vel / tgt / Vlim / Vbus / dir / zero） |

## 2. 环境要求

| 项目 | 要求 |
|---|---|
| 浏览器 | **Chrome / Edge 89+**（Firefox、Safari 不支持 Web Serial） |
| 系统 | Windows 10/11 |
| 硬件 | USB-TTL（CH340 / CP2102 等），接蓝板 **PA2(TX) / PA3(RX)**，**共地** |

打开方式：**直接双击 `index.html`**（`file://` 下 Chrome 允许 Web Serial）。

---

## 3. 使用步骤

1. 驱动小板、蓝板分别上电，USB-TTL 插到电脑。
2. 双击 `index.html`。
3. 点 **连接串口** → 选择 USB-TTL 对应的 COM 口。
4. 连接后页面会自动发一次 `?`，状态栏出现数值即通信正常。
5. **确认安全后再点「使能电机」**（会弹确认框）。
6. 用快速目标、步进微调或直接输入角度控制位置。

> ⚠️ **按 Esc 键可随时急停**（发送 `D`）。

## 4. 界面功能

| 区域 | 说明 |
|---|---|
| **设备连接** | 选择 COM 口；波特率默认 115200 |
| **实时状态** | 使能状态 / 实际角度 / 实际速度 / 目标角度 / 电压上限 / 母线电压 / 传感器方向 / 电角度零点；可开 400ms 自动轮询 |
| **电机控制** | 使能（带二次确认）、失能/急停、目标角度输入、快速目标（±π/2 等）、步进微调（±0.01 ~ ±1.0） |
| **参数设置** | 电压上限（带电流估算与超额定警告）、速度上限 |
| **串口日志** | 显示所有收发内容，可清空 |

### 与旧版的区别

**已移除**「开环诊断」和「编码器诊断」两个面板。

原因：改用**官方 SimpleFOC 库**后不需要这些工具 —— 官方库会自己完成
对齐（`initFOC`），位置环能正常工作即说明编码器与换相都正确。
旧版那些诊断命令（`H/S/P/O/N/G/A/Y/Z/Q/W`）在新固件里不存在。

## 5. 安全设计

电机的实测参数：**相电阻约 3.8 Ω，额定电流 1.4 A，24 V 系统**。

| 措施 | 说明 |
|---|---|
| 上电默认**失能** | 必须手动点「使能」，且会弹确认框 |
| 电压上限默认 **1.5 V** | 约 0.4 A，只有额定的 29% |
| 电压输入实时估算电流 | 超过 1.4 A 变红提示 |
| 设置 >3 V 二次确认 | 提示会超过额定电流 |
| Esc 快捷键急停 | 任何时候都能立即断电 |

**第一次测试请务必**：电机固定好、手放在电源开关上、用电流表监控。
预期电流 < 0.4 A。确认正常后每次只加 0.5 V。

## 6. 常见问题

**连接后没有数据？**
- 确认 USB-TTL 的 TX 接蓝板 PA3、RX 接 PA2（**交叉**），并共地
- 确认固件已烧录且正在运行（板子 PC13 LED 应有心跳闪烁）
- 拔插一次 USB-TTL，看 COM 口是否变化

**状态栏一直不更新？**
- 勾选「每 400ms 自动刷新」，或点「读取一次状态」
- 固件在失能状态下也会正常回应 `?`

**点使能后电机不动？**
- 电压上限 1.5 V 对应力矩较小，属正常
- 发 `R` 看编码器角度是否合理
- 先试「以当前位置为目标」再给一个小角度（如 `T0.1`）

**要急停怎么办？**
- 点「失能 / 急停」，或直接按 **Esc**
- 最可靠的是直接切断电源
