# G431 闭环打通记录（2026-10-27）

板子：STM32G431CBT6 + DRV8316C（v1.1 自制板）+ AS5600 + 24V 电池
固件：`New_gimbal/keil5_g431`（Keil5，烧录一律 `mode=UR`）

## 结论先写

1. **开环正弦换相能连续转动**，实测位移与理论差约 12%（开环滑差）。
2. **极对数实为 11**（电机参数表写的 7 是错的，与 F103 配置一致），编码器**方向 -1**，**电气零点 1.697 rad**。
3. **位置闭环收敛**：0.3 rad 与 1.0 rad 阶跃稳态误差 ≤0.0026 rad（0.15°），3 rad 阶跃 ≤0.0040 rad（0.23°）。
4. **电压上限可以从 2.5 V 抬到 8 V 而电流不涨**：3 rad 阶跃下峰值相电流 0.77 A→0.30 A（上限越高反而越低），全部远低于 1.4 A 额定。位置环只取它需要的电压，抬高上限只是让加速更从容。
5. **CAN 仍不可用**：TJA1042T 的 VCC 取自板上 5V 网络，本板 DRV 内部 buck 已坏、当前只接了 ST-Link 的 3.3 V → 收发器无电。

## 第一步：开环转动

`bench_spin_run(0.8f, 6.2831853f, 4000u)` —— 0.8 V 幅值、1 Hz 电频率、4 s：

| 项 | 值 |
| --- | --- |
| 结果码 | 0（跑满） |
| nFAULT | 1 |
| 峰值相电流 | 0.355 A |
| 跳闸 | 0 |
| 三相均值 | 0.0048 / 0.0068 / 0.0004 A（平衡） |
| 机械角 | 3.0266 → 1.0079 rad，位移 **-2.009 rad** |
| 参考 | 4 个电周期 / 11 极对 = 2.284 rad，差 12%（开环滑差） |

结论：电机连续转动，编码器读数随旋转递减 → 方向为负。

## 第二步：零点 / 方向 / 极对数标定

方法：`bench_align_run()` 用纯 d 轴矢量把转子磁极拉到指定电角度，保持 2.5 s 让转子稳定，取最后 200 ms 的平均机械角。d 轴电压 1.5 V。

| 行 | 指令电角度 | 稳定机械角 (rad) | 峰值电流 |
| --- | --- | --- | --- |
| 0 | 0 | 0.98788 | 0.67 A |
| 1 | 0 | 0.98995 | 0.75 A |
| 2 | π/2 | 0.83907 | 0.72 A |
| 3 | π | 0.70716 | 0.73 A |

两次 θ=0 的重复性 0.0021 rad 机械角（0.023 rad 电角 ≈1.3°）→ 测量可靠。

按 `zero = (-pp*m - theta) mod 2π` 扫极对数：

| 极对数 | 零点最大偏差 |
| --- | --- |
| 7 | 42.8° |
| 9 | 22.9° |
| 10 | 12.9° |
| **11** | **3.94°**（zero = 1.6971 rad） |
| 12 | 7.4° |
| 13 | 17.0° |

→ **pp = 11、方向 = -1、零点 = 1.6971 rad**，已写入 `User/motor_config.h`：

```c
#define MOTOR_SENSOR_DIRECTION -1
#define MOTOR_ZERO_ELECTRIC     1.697f
```

## 第三步：位置闭环阶跃与电压上限扫描

`bench_cl_run(&motor, 上限V, 步长rad, 稳定ms, 保持ms, 步数)`：

| 上限 | 步长×步数 | 结果码 | 峰值相电流 | 逐步误差 (rad) |
| --- | --- | --- | --- | --- |
| 2.0 V | 0.3×3 | 0 | 0.166 A | 0.0009 / -0.0013 / +0.0026 |
| 2.5 V | 1.0×3 | 0 | 0.182 A | 0.0014 / -0.0003 / -0.0005 |
| 2.5 V | 3.0×3 | 0 | **0.773 A** | — |
| 4.0 V | 3.0×3 | 0 | 0.369 A | — |
| 6.0 V | 3.0×3 | 0 | 0.353 A | — |
| 8.0 V | 3.0×3 | 0 | 0.299 A | -0.0020 / -0.0040 / +0.0001 |

全部 `trips=0`、跳闸 0 次、结束后正常失能。

**为什么上限越高电流越小**：位置环输出 `q` 被上限钳住，上限越低越容易长时间饱和（接近堵转工况，反电动势压不住），电流反而更大。上限抬高后同样位移只需要很小的 `q`。所以"怕烧电机"不该靠压低电压上限，而应靠**电流环限幅**——本工程的三路低侧采样 + 折叠 + I²t 正是干这个的。

最坏一次 0.773 A 出现在 2.5 V 上限（长时间饱和），仍只有额定 1.4 A 的 55%。

## 本轮顺带修掉的三个 ADC 根因

1. **ADC12 时钟不能用 PLLP**：`RCC_CCIPR.ADC12SEL=0b01`(PLLP) 时 `ADC_CR.ADCAL` 永不完成（实测 `CR=0x90000000` 卡死）；改 `0b10`(SYSCLK)，`ADC_CCR.PRESC=/4` → 42.5 MHz，校准立刻完成（`CALFACT=0x3F`）。
2. **`ADC_CFGR_JQDIS` 必须置 1** 才能用软件触发注入组：JQDIS=0 且 `JSQR.JEXTEN=0` 时写 `JADSTART` 只是武装、永不转换（ST HAL `HAL_ADCEx_InjectedStart()` 把这个组合判定为"队列为空"）。且改 JQDIS 会清空 JSQR，必须先写 CFGR 再配序列。
3. **TIM1_CC4 直接触发（JEXTSEL=1）在本板不产生转换**：TIM1 的 `CC4IF` 确实置位、`CCMR2` 的 OC4M=7/OC4PE 也对，但 ADC 就是不动；改用 **TIM1_TRGO**（`TIM1->CR2.MMS=7`，OC4REF 作 TRGO，`JEXTSEL=0`）立刻工作。固件保留"CC4 先试、失败自动切 TRGO"，诊断字段 `cs_trig` 记录当前路线（本机稳定为 2）。

另外：**nFAULT 上电会锁存为低**（VM 爬升），旧逻辑一旦 EXTI 触发就让驱动永久睡眠，SOx 偏置从 1.72 V 掉到 0.6 V，零点标定必然失败。现在 `board_driver_set(1)` 会先脉冲一次 nSLEEP 复位锁存，主循环空闲时每 500 ms 自恢复并重标零。

## 台架自测工具（无 CAN 也能验证）

`User/bench_current.c` 提供四个自测入口，由 `User/motor_config.h` 的宏开关（任一为 1 时自动 `G431_BENCH_MODE=1` 并跳过 CAN，否则 bus-off 会持续请求停机）：

| 宏 | 内容 |
| --- | --- |
| `G431_BENCH_CURRENT_TEST` | 7 步直流锁相（偏置 + A-B/B-C/C-A ±0.6 V），验三通道极性 |
| `G431_CURRENT_LOCK_TEST` | 30 s 单相锁相 / 20 s 静默，方便万用表读真实电流 |
| `G431_SPIN_TEST` | 开环正弦转动 |
| `G431_ALIGN_TEST` | d 轴锁相标定零点/方向/极对数 |
| `G431_CLOSEDLOOP_TEST` | 位置闭环阶跃 + 电压上限扫描 |

结果数组通过 SWD 读：`arm-none-eabi-nm Objects\gimbal_g431.axf` 取符号地址（每次改代码都会移位），再
`STM32_Programmer_CLI -c port=SWD mode=HOTPLUG freq=1000 -r32 <地址> <字节数>`，按小端拼回 float。
交付固件请把五个宏全部置 0。
