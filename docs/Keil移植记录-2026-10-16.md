# Keil5 标准库移植记录（2026-10-16）

当前独立工程：`../keil5_foc/gimbal_foc.uvprojx`，使用 STM32F103C8T6、SPL V3.5.0、
纯 C99、ARM Compiler 5.06。使用说明与验证范围见 [工程 README](../keil5_foc/README.md)。

迁移源为 `../foc_official/src/main.cpp` 最新版本。保留 11 极对、方向 CW、固定零点
0.92 rad、3V 初始上限、速度 PI 0.2/5、速度滤波 0.05s、位置 P=20、4rad/s 目标斜坡，
以及上电实际转一机械圈后失能的行为。启动跳过方向/零点扫角。

采用官方 SimpleFOC 2.4.0 算法的 C 实现，未沿用厂家旧版中的 TIM2 PWM 和 SysTick /9
计时逻辑。PWM 使用 TIM1 PA8/9/10，EN 使用 PB0，串口使用 USART2 PA2/3，
编码器使用 I2C1 PB6/7；命令与现有 Web 控制器兼容。

完成 Keil 全量重编译，0 错误、0 警告，生成 AXF/HEX；Flash 装载内容 13,700 字节，
静态 RAM（含栈/堆）3,904 字节。通过离线数值与状态测试。

尚未对 Keil 固件做烧录、上电和声学测试。COM8 占用使得本次未能发送 D，
不能据此确认设备当前使能状态。后续硬件验证应读取启动日志，确认单圈完成和 EN=OFF，
再短时验证 E、小角度及正反整圈；每次测试结束确认 D/EN=OFF。

`code/4_closeloop_M1` 和 `code/4_closeloop_M1_bluepill` 是历史版本，
本次不再向这些旧目录同步。后续 Keil 开发请使用新独立工程，避免误烧旧参数。
