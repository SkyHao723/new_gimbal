# 安全架构（七层保护）

> 建立日期：2026-10-15
> 背景：此前发生 4 次电机过热事故，必须从架构上根治
> 固件：`app/safe_test.c`

---

## 一、为什么会反复烧：唯一的保护层本身不可靠

之前的保护代码：

```c
for(i = 0; i < N; i++) {
    ...
    if(cur_max() > i_limit) { 停 }   // ← 所有保护都靠这一行
    dly_ms(10);                       // ← 每 10ms 才检查一次
}
```

**三个致命缺陷：**

| 缺陷 | 后果 |
|---|---|
| 每 10ms 检查一次 | 10ms = **250 个 PWM 周期**，电流早已冲上去 |
| 依赖电流读数 | 而读数有零点漂移（实测漂 94 counts）、采样错位 |
| 只有一层 | 这层失效就完全没有保护 |

**根本问题：用一个不可靠的传感器，驱动唯一的保护动作。**

---

## 二、七层保护设计

**核心思想：任何一层失效，其他层仍能阻止烧毁。**

| 层 | 机制 | 响应 | 依赖电流读数 |
|---|---|---|---|
| **1** | 极低起步电压 1.0V（≈0.26A） | 永久 | ❌ |
| **2** | **唯一出口硬限幅** | 每次调用 | ❌ |
| **3** | 过流阈值 0.8A（额定的 57%） | 1ms | ✅ |
| **4** | 每步检查（1ms，不是 10ms） | 1ms | ✅ |
| **5** | 零点自动重标（治本） | 每次启动前 | — |
| **6** | 超时自动停 5 秒 | 5s | ❌ |
| **7** | 零点漂移门槛，超标拒绝启动 | 每次启动前 | ✅ |

### 第 2 层是关键：保护放在"唯一出口"上

所有电压输出都经过同一个函数，限幅写在函数入口 —— **任何代码路径都绕不过**：

```c
static void set_phase_voltage(float Uq, float ang)
{
    /* ★ 硬限幅：不依赖任何传感器 */
    if(Uq >  V_ABS_MAX) Uq =  V_ABS_MAX;   /* 2.0V 绝对上限 */
    if(Uq < -V_ABS_MAX) Uq = -V_ABS_MAX;
    if(Uq >  v_cmd)     Uq =  v_cmd;       /* 再受用户命令约束 */
    if(Uq < -v_cmd)     Uq = -v_cmd;
    v_used = Uq;
    ...
}
```

**即使上层代码写错、请求 12V，实际也只能输出 2V。**

### 第 6 层：超时保护

前几次事故都是"跑到一半没人管"。加超时后，**最坏情况也只通 5 秒**。

### 第 5 层：零点自动重标（治本）

实测零点漂移证据：

```
电机【关闭】时固件却显示 I = 0.205 A
ADC 原始值 1777，标定零点 1683  →  漂了 94 counts（≈0.25A）
```

漂 300 counts 就会凭空多出 0.8A 假读数 —— **这很可能就是"1.6A 烫电机"事件的真相**。

**措施**：每次启动电机前重新标定零点；漂移超阈值就拒绝启动。

### 硬件关断：MOE

```c
static void motor_off(void)
{
    TIM1->CCR1=0; TIM1->CCR2=0; TIM1->CCR3=0;
    GPIO_ResetBits(GPIOB, GPIO_Pin_0);    /* EN 拉低 */
    TIM_CtrlPWMOutputs(TIM1, DISABLE);    /* ★ MOE=0，硬件关断 */
}
```

**为什么必须关 MOE**：正弦换相在 `Uq=0` 时输出 50% 占空比
（三相都是 720，互差为 0，不出力但寄存器不是 0）。只清 CCR 不够，
**关掉 MOE 才是硬件层面的彻底关断**。

## 四、硬件措施（当前缺失）

> 用户反馈：**电源没有限流功能，回路里也没有保险丝。**

这意味着**唯一不依赖软件的保护层缺失**。建议补上：

### 优先方案：限流电源
实验室可调电源设限流 1.5A —— 电流一到自动降压，物理上不可能烧。

### 次选：保险丝
电源到驱动板之间串 **2A 快断保险丝**（几毛钱）。
**价值**：未来任何一次固件出错都能救电机。

### 临时替代：串联电阻
大功率电阻（如 10Ω/10W）串联，电流被物理限制在 `24V/10Ω ≈ 2.4A`。

**在补上任意一种之前，所有测试都必须：**
- 电压 ≤ 1V
- 有人全程盯着
- 单次 ≤ 5 秒（固件已有超时）
- 事先摸过电机温度（热的绝不上电）

## 六、下一步

1. **先补一层硬件保护**（限流电源 / 保险丝 / 串联电阻，任选其一）
2. 接上电机，发 `V` 自检，确认零点漂移在阈值内
3. 发 `C` 标定，再发 `S` 旋转 —— **单次只通 1~5 秒**
4. 全程用**电流表实时监控**（不要只信固件读数）
5. 只有在 1V 下电流完全符合预期（≈0.26A）后，才逐步升到 1.5V、2V

### 禁止清单

- ❌ 直流锁死测试（`B<x>` 命令，无天然限流，最危险）
- ❌ 无人监控的长时间通电
- ❌ 电压超过 2V（当前阶段）
- ❌ 在零点漂移超标时启动电机
