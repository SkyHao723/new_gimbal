## 判断与优化方向

当前 PI 与位置 P 在这些工况下配合正常：跟踪误差的采样峰值约 0.53～1.10°，末段没有明显来回摆动。正反整圈规划约 2.20 秒，实际进入 ±0.3° 约 2.16～2.19 秒，因此这组整圈动作的时间主要受轨迹规划约束。盲目提高 PI/P 并不能显著突破规划时长。

轨迹从静止运动 2π 时，按加速 8、减速 4 计算的三角形峰速为 sqrt(2×8×4×2π/(8+4))≈5.79rad/s，尚未触及 6rad/s 的巡航限制；单独提高最高轨迹速度，对本次半圈和整圈动作理论上几乎没有收益。若优先提速，应在维持末段稳定的前提下比较加减速度；若优先柔和，应比较限制加速度变化率的轨迹。到位干脆程度则需要加入不同停止角度和方向的重复测试。

## 数据解释与边界

- 状态采样约 37Hz，未捕捉到的短促超调不能排除。进入并保持指本次记录剩余期间均在 ±0.3° 内；不是无限时间保证。
- 角度来自 AS5600，12 位约 0.088°/计数。摆幅 0.000° 只代表采样显示未变，不能据此声称机械绝对静止或绝对定位达到该精度。
- 时间从脚本发送目标后开始计，包含串口与主机调度影响。规划结束也取首次观测，不是板端精确时间戳。
- 各动作相对于当次起点，失能后会有齿槽回落，不属于使能保持误差。最终 EN=OFF 的角度未纳入运动统计。
- uq 是控制输出电压指令，没有测量实际相电压、相电流、噪声、温度或负载性能。采样最大 |uq| 为 1.949V，没有观察到 3V 限幅；此结论不排除采样之间存在峰值。
- 当前仍是电压力矩控制，没有电流闭环；上电单圈自检仍启用。本轮没有复位来触发自检。
