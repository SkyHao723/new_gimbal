## 一、电机健康状况：**未损伤** ✅

| 电机 | 两相电阻（万用表） | 说明 |
|---|---|---|
| 全新未拆封同款 | **3.8 Ω** | 基准值 |
| 被烫过的电机 | **4.4 Ω** | +16% |

### 判断依据

**绕组过热短路会让电阻变小，不会变大。** 现在是 4.4Ω（略大），
最可能是：
- 漆包线轻微退火（电阻率略升）
- 或两次测量的接触电阻差异

**结论：没有匝间短路，电机可用。**

### 重要更正

之前我怀疑"万用表 3.8Ω 偏大（因为驱动板并联）"—— **这个怀疑是错的**。
用**两台独立电机**测出同一个值 3.8Ω，说明万用表读数是可信的。

## 二、电流采样精度：**基本准确，但零点会漂移**

### 准确的部分

用户用独立电流表实测 B2 测试：
```
固件读数 = 1.62 A
电流表   = 1.6 A      ← 吻合
```
**`A_per_cnt = 0.00269 A/count` 是正确的。**

### 问题：零点漂移导致假读数

证据：电机**关闭**时固件却显示 `I = 0.205 A`，ADC 原始值 1777，
而标定时的零点在 1683 —— **漂了 94 counts（≈0.25A）**。

漂移发生在：
- 板子重启后
- EN 使能/失能状态改变后
- CSA 工作点变化后

**后果**：漂移 300 counts 就会凭空多出 0.8A 的假读数 ——
这很可能就是之前"1.6A 烫电机"事件的真相（真实电流只有 0.53A）。

### 修复措施

1. **每次测量前自动重标零点**（在 EN 稳定后）
2. **零点漂移超过阈值就报警**，不采用该读数
3. 标定用的 `B<x>` 命令每次进入时先重标零点

## 四、过热事故的最终解释

```
真实电阻 3.8 Ω
B2 施加 A-B 间 2V  →  真实电流应该是 2/3.8 = 0.53 A
固件显示 1.62 A    →  多出的 1.1A 来自零点漂移
```

**所以：**
- 电机实际只承受了约 0.53A（额定 1.4A 的 38%）——**这就是电机没坏的原因**
- 固件和电流表**都**读到了 1.6A（电流表可能也受同一次漂移影响，
  或它读到的是瞬态峰值）

**功率计数据（3V→0.084A）与 3.8Ω 不符（应 0.79A）** ——
原因待查，但功率计在低电流段分辨率差，不作为主要依据。

> ⚠️ **仍有一条未解释清的矛盾**：功率计读数与欧姆定律不符。
> 在彻底查清前，**任何测试都要用电流表实时监控**，不能只看固件读数。

## 五、PWM 采样错位的另一个问题（仍需解决）

即便零点准确，ADC 采样仍与 PWM 不同步：

```
PWM 开启时读数在 0.005A 和 0.3A 之间交替
原因：ADC 自由转换（~200kHz）与 25kHz PWM 不同步
      32 次平均只覆盖 0.16ms，PWM 周期 0.04ms
```

**解法**（F103 的限制）：
- F103 的 TIM1 只有 CC1/CC2/CC3 能触发 ADC，CC4 不行
- 可用 **TIM1 更新事件**或**降低 PWM 频率**（如 10kHz）来同步
- 或改用**注入组 + 定时器触发**

**在解决前，电流读数只能用于"粗略保护"，不能用于电流环。**
