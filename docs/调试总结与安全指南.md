## 四、调试过程中发现并修复的 4 个关键问题

### 问题 1（★ 电机不转的直接原因）：`setPhaseVoltage` 写错定时器

```c
/* 原代码（错误） */
TIM_SetCompare1(TIM2, Ta*PWM_Period);   // PWM 在 TIM1，写 TIM2 等于没写
```

PWM 输出改到 TIM1(PA8/9/10) 后，这个函数还在写 TIM2 —— FOC 算出的占空比
全部写进一个没接输出的定时器，**PA8/9/10 上永远只有 0**。

**修复**：改为 `TIM_SetCompare1(TIM1, ...)`（`SimpleFOC/BLDCMotor.c`）

### 问题 2：`SystemInit()` 不配置 PLL

原工程实际跑 **HSI 8 MHz** 而非 72 MHz：
- PWM 频率从 25 kHz 变成 **2.8 kHz**
- I2C 时序假设全错

**修复**：显式配置 PLL 到 72 MHz（HSE 8MHz × 9），失败退回 HSI 64 MHz。

### 问题 3：I2C 读超时后总线卡死

`I2C_getRawCount()` 所有超时路径直接 `return 0`，**不产生 STOP**，
主机把 SCL 拉死 → 之后每次读都失败 → `angle` 恒为 0。

**修复**：加 `I2C_ReadAbort()`，超时时产生 STOP、清 POS 位、恢复 ACK；
两处无超时的死等也补上保护。

### 问题 4：电流采样零点在 EN 使能前后漂移

CSA 在 EN 拉高后才工作，输出基线整体抬高约 **290 counts（0.78 A）**。

**修复**：零点必须在 **EN 使能之后**标定（上电时序：EN → 延时 300ms → 标定零点）。

## 五、两套固件

### 固件 A：`mini_test.c`（★ 已验证可用，安全性最高）

- **完全不依赖 SimpleFOC 库**，只用 SPL，逻辑简单到可以逐行检查
- 六步换相，不用编码器
- 内置电流采样 + **过流硬切断**（超阈值立即 EN 拉低）
- **已实测：成功转动，空载电流 < 0.1 A**

**命令**：

| 命令 | 作用 |
|---|---|
| `?` | 状态（EN/保护/电压/电流/CCR） |
| `E` / `D` | 使能 / 失能（急停） |
| `V<x>` | 电压上限（V） |
| `L<x>` | 过流阈值（A） |
| `C0` / `C1` | 过流保护 关 / 开 |
| `S<x>` | 每步毫秒数（默认 20，越大越慢） |
| `R` | 开始旋转（带保护，自动停） |
| `Z` | 零电流测试（锁定转子，逐步加压测电流） |
| `I` | 读电流 |
| `K` | 重新标定电流零点 |
| `J<x>` | 电流标定系数 |

**安全测试流程**：

```
V2      限压 2V（约 0.3A）
L1.5    过流 1.5A
C1      打开保护
S60     每步 60ms（慢）
R       旋转
```

### 固件 B：`user/main.c`（正式固件，带闭环）

在参考工程基础上做了安全性重构：
- 时钟配置到 72 MHz
- 参数集中在文件头部，注释写明依据
- **上电默认失能**，分阶段启动（失能 → 使能 → 对齐）
- 启动时打印完整安全参数供核对
- `D` 命令急停、`V/G/L` 在线调参并带范围钳制与警告
- ⚠️ **闭环（编码器对齐）尚未验证通过**，需要先确认 AS5600 通信稳定

## 六、安全操作规程

### 上电前
1. 万用表量电机两相之间电阻，确认约 **6.5 Ω**（不是 0，也不是无穷大）
2. 确认驱动板电源、蓝板电源、GND 都接对
3. 确认 `voltage_limit` ≤ 5 V（首次测试）

### 首次测试
1. **先不接电机**，量 PA8/PA9/PA10 有 25 kHz PWM
2. 按「固件 A 安全测试流程」从 2 V 起
3. **手放在电源开关上**，盯着电流表

### 判据（出现任一立即断电）
| 现象 | 含义 |
|---|---|
| 电流 > 1.5 A | 超额，可能在失步或堵转 |
| 电机烫手 | 立即停，等冷却 |
| 异响/抖动 | 换相不对或失步 |
| 电流突然飙升 | 立即断电 |

### 危险操作（绝对避免）
- ❌ `voltage_limit` 超过 10 V
- ❌ 开环旋转时把每步毫秒数设得太小（磁场太快 → 失步 → 堵转 → 大电流）
- ❌ 电机未固定就上电
- ❌ 电机烫手时继续通电

## 七、145 W 事故复盘

**当时的配置**：`voltage_limit = 12 V` + 开环每步 5 ms

**发生的事**：
1. 12 V 对应约 1.85 A（132% 额定），本身已超额
2. 开环磁场转太快，转子跟不上 → **失步**
3. 失步后等效于**堵转**，电流按 `24V / 6.5Ω ≈ 3.7 A` 走
4. `24 V × ~6 A ≈ 145 W` 灌进 **33 W 的电机**

**教训**：
- 开环控制**必须**从极低速开始，逐步加速
- 电流保护**必须**有（软件 + 电源限流双保险）
- 任何参数调整后，第一次测试都要用最低电压
