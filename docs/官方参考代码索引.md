BLDCMotor motor = BLDCMotor(11);                          // 极对数

## 二、关键发现：「起动死点」问题的官方解法

### 对比：官方 vs 厂家移植版 vs 我的实现

| 环节 | 官方 SimpleFOC | 厂家移植版 (2019) | 我的实现 |
|---|---|---|---|
| 方向标定 | 正转一圈→反转一圈，比 `mid_angle`/`end_angle` | **相同** | 未做（用了绝对编码器直读） |
| **零点标定** | `setPhaseVoltage(3V, 0, _3PI_2)` → 等 700ms → 读传感器 | **相同**（但**漏了读传感器后的归一化**） | 锁在 **0** 度 → 算 offset |
| SVPWM | Inverse Park + Clarke + Midpoint Clamp | 扇区查表法 | 三相正弦（等价） |
| 速度环 | P=0.2, **I=20** | P=0.1, I=2 | P=0.5, **I=1.0** ← 积分弱 20 倍 |

### ★ 死点的真正原因

**官方做法**：把零点标定在 **电角度 270°（`_3PI_2`）**。

**我的做法**：把零点标定在 **电角度 0°**。

区别在于闭环第一次换相时的力矩：

```
力矩 T ∝ sin(θ_field − θ_rotor)

我（零点在 0°）:   T ∝ sin(0)   = 0    ← 死点！给多大电压都不动
官方（零点在 270°）: T ∝ sin(270°) = −1  ← 满力矩，立刻起转
```

**这就是为什么我的闭环"施加电压但转子完全不动、电流只有 0.02A"** ——
力矩恒为 0，不是电压不够。

而且这形成自锁：
```
转子不动 → 编码器不变 → 电角度不变 → 磁场静止 → 力矩恒为 0
```

### 修复方案（明确）

**把零点标定改到 270°**，与官方一致：

```c
/* 标定 */
setPhaseVoltage(voltage_align, 0, _3PI_2);   /* 270° 而不是 0° */
delay_ms(700);                                /* 等转子对齐 */
zero_electric_angle = electricalAngle();      /* 用官方公式 */

/* 之后闭环换相 */
angle_el = _normalizeAngle(
    (shaft_angle + sensor_offset) * pole_pairs - zero_electric_angle);
```

## 三、官方 SVPWM 与我的实现等价性验证

官方 `SinePWM`（`BLDCMotor.cpp`）:

```c
Ualpha = _ca*Ud - _sa*Uq;          // _ca=_cos(angle), _sa=_sin(angle)
Ubeta  = _sa*Ud + _ca*Uq;
Ua = Ualpha;
Ub = -0.5*Ualpha + _SQRT3_2*Ubeta;
Uc = -0.5*Ualpha - _SQRT3_2*Ubeta;
```

代入 `Ud = 0`：

```
Ualpha = -sin(θ)·Uq
Ubeta  =  cos(θ)·Uq

Ua = -Uq·sin(θ)
Ub =  0.5·Uq·sin(θ) + 0.866·Uq·cos(θ) = Uq·sin(θ − 120°)
Uc =  0.5·Uq·sin(θ) − 0.866·Uq·cos(θ) = Uq·sin(θ + 120°)
```

即 **三相正弦、互差 120°** —— 与我的 `set_phase_voltage()` **完全等价**。

**结论**：我的换相函数没写错，问题纯粹在零点标定的角度上。

## 四、需要向官方对齐的参数

| 参数 | 官方值 | 我的值 | 建议 |
|---|---|---|---|
| `voltage_sensor_align` | 3 V | 2~3 V | 保持 3V |
| `voltage_limit` | 6 V | 2~5 V | 闭环时用 5~6V |
| `PID_velocity.P` | **0.2** | 0.5 | 改 0.2 |
| `PID_velocity.I` | **20** | 1.0 | ★ 改 20（关键） |
| `PID_velocity.output_ramp` | **1000** | 无 | 加上 |
| `LPF_velocity.Tf` | 0.01 | 无 | 加上 |
| `P_angle.P` | 20 | — | 位置环用 |
| `velocity_limit` | 4 rad/s | 2 | 保持小值先测 |
| 零点标定角度 | **270°** | 0° | ★★ 必须改 |

**注意**：官方例程用 `voltage_power_supply=12V`、`voltage_limit=6V`。
我们的板子供电是 24V，所以 `voltage_limit` 要按电流重新算：
`I ≈ V/6.5`，6V → 0.92A（额定 1.4A 的 66%），安全。

## 五、实测验证（2026-10-15 晚）

### ★ 电机在闭环下确实能动了

用 `T` 命令（四个固定电角度偏移各保持 2 秒）实测：

| 电角度偏移 | 机械角变化 | 移动量 | 电流读数 |
|---|---|---|---|
| 0° | -0.6473 → -0.4479 | 0.1994 rad | 0.041 A |
| 90° | -0.4479 → -0.0752 | 0.3728 rad | 0.011 A |
| 180° | -0.0752 → 0.3099 | 0.3850 rad | 0.567 A |
| 270° | （输出被截断） | — | — |

**累计移动约 0.96 rad（55°）**，且每个角度都在移动。

**结论**：
1. ✅ 换相关系正确，转子能跟随磁场（闭环通路是通的）
2. ⚠️ `sin(0)=0` 死点理论**不完全成立** —— off=0° 时也移动了 0.2 rad
   （原因：转子有摩擦/齿槽力矩，会稳定在略偏离磁场的位置，不会精确停在 0°）
3. ❌ **电流采样在电机运行时不可信**：off=180° 时 0.567A，其他角度只有 0.01~0.04A

### 结论：真正的主要障碍已从"死点"转为"电流采样不可信"

慢速/静态时电流采样准确（Z 测试与 6.5Ω 吻合），但**电机运行时误差很大**。
这会导致：
- 过流保护误动作（之前多次 4~5A 尖峰很可能是读数虚高）
- 无法做电流环

**必须解决**：用外部电流表标定 `A_per_cnt` 系数，或用
`代码开源\STM32F405_SFOCminiV2-带电流采样.zip` 对照正确接法。

## 六、下一步实施计划

1. **改零点标定角度**：`_3PI_2`（270°）而非 0°
2. **对齐官方 PID**：`P=0.2`, `I=20`, `output_ramp=1000`, `LPF Tf=0.01`
3. **电压上限设 5V**（≈0.77A，留余量）
4. **先测力矩模式**（给固定电压，看转子是否锁住且电流符合 `V/6.5`）
5. 再测速度环，最后位置环
6. 若仍不动，用 `代码开源\STM32F405_SFOCminiV2-带电流采样.zip` 对照电流采样部分
