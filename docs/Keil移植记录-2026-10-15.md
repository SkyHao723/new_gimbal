# Keil 工程移植记录（2026-10-15）

> 2026-10-16 更新：本文为旧版同步记录。最新纯 C 标准库工程已建立在
> `../keil5_foc/`，详情见 [新移植记录](Keil移植记录-2026-10-16.md)。

PlatformIO 版本先把速度反馈低通时间常数从 `0.01s` 调到 `0.05s`，用于压低 AS5600 差分测速噪声。对应逻辑已同步到 `code/4_closeloop_M1` 的 Keil/SPL 工程。

已同步的硬件映射和安全参数：

- 三相 PWM 改为 TIM1 CH1/CH2/CH3：PA8/PA9/PA10；修复原工程向 TIM2 写比较寄存器的问题。
- 使能脚改为 PB0，保持上电默认失能；FOC 对齐完成后再次失能，等待 `E` 命令。
- 串口改为 USART2：PA2/PA3，115200 8N1，避免与 PWM 使用的 PA9/PA10 冲突。
- 串口接收改为 16 条命令队列，支持连续命令；命令集为 `E D T<n> V<n> L<n> R ? H`。
- 母线参数为 24V，初始电压上限 3V，对齐电压 3V；运行时 `V` 命令上限硬限制为 5V。
- 位置控制参数为速度环 `P=0.2, I=20, ramp=1000`，角度环 `P=20, D=0`，速度低通 `Tf=0.05s`。

Keil 工程仍使用原有 SPL 和自带 SimpleFOC C 实现，未引入 Arduino 依赖。已用 `arm-none-eabi-gcc -fsyntax-only` 对修改的 `main.c`、定时器、串口、FOC、PID 和低通滤波源码完成语法检查；最终烧录前仍需在 Keil µVision 中完整构建，并在限流/保险丝和电流表条件下做短时硬件验证。
